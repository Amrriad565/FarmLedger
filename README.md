# حسابات الأرض — تطبيق Android

تطبيق لتسجيل وارد ومنصرف الأرض الزراعية. بيشتغل من غير نت، والبيانات بتتحفظ على الموبايل.

## طريقة 1: Android Studio (الأسهل)
1. افتح Android Studio ← **Open** ← اختار فولدر `FarmLedger`.
2. استنى لحد ما الـ Gradle sync يخلص (أول مرة بينزّل حاجات من النت).
3. من القائمة: **Build ← Build App Bundle(s) / APK(s) ← Build APK(s)**.
4. هتلاقي الملف في `app/build/outputs/apk/debug/app-debug.apk`.
   - ولو عايز نسخة release: افتح Terminal في Studio واكتب `gradlew assembleRelease`، وهتلاقيها في `app/build/outputs/apk/release/`.

## طريقة 2: GitHub (من غير ما تنزّل حاجة)
1. اعمل repo جديد على GitHub وارفع عليه الفولدر ده كله.
2. ادخل تبويب **Actions**، والـ workflow اللي اسمه "Build APK" هيشتغل لوحده.
3. لما يخلص (حوالي 5 دقايق) افتح الـ run، ونزّل `FarmLedger-apk` من **Artifacts**.

## التثبيت على الموبايل
انقل الـ APK للموبايل وافتحه، ووافق على "التثبيت من مصادر غير معروفة".

## ملاحظات
- النسخة دي متوقّعة بمفتاح الـ debug، يعني تتثبت عادي بس ماينفعش ترفعها على Google Play.
  ولو حابب ترفعها، اعمل keystore خاص بيك وغيّر `signingConfig` في `app/build.gradle`.
- **الإصدارات الجاية لازم تتبني من نفس الجهاز أو نفس الـ keystore**، عشان الموبايل يقبل التحديث من غير ما تمسح التطبيق وتخسر بياناتك.
- واجهة التطبيق كلها في `app/src/main/assets/index.html`، وتقدر تعدّل البنود من الـ `CATS` اللي فيها.
- البيانات بتتحفظ جوه التطبيق، **ولو مسحت التطبيق هتتمسح معاه**. فاعمل "نسخة احتياطية" كل فترة، وهتلاقيها في `Download/FarmLedger`.
